# Calibration table reference

Generated by `tools/gen_cal_docs.py` from the table definitions (derived from the MP Tune definition files). Addresses are the same for every calibration built on code base B4CC. Descriptions are the original English ones (many are still placeholders), except where the MP Tune address or long name does not fit the code: there the description says what the code does and gives the MP Tune address or long name.

Type codes: 0 = 2D point-slope curve, 2 = 2D curve (other format), 3 = byte constant, 4 = word constant, 5 = bit flags, 7 = 3D map (rows x cols), 9 = address list, 11 = O2 ramp kick table, 17 = 3D map with its own axis.
