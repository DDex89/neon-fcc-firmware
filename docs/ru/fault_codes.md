# Коды ошибок

Генерируется `tools/gen_fault_docs.py` из дескрипторов ошибок по адресу `$D4E3` (160 записей по 8 байт, индекс × 8 + $D4E3). Не редактируйте вручную.

## Формат дескриптора

| Byte | |
|---|---|
| +0 | Индекс ошибки (0-159) |
| +1 | Счётчик созревания: сколько неудачных проверок до записи кода (1 = сразу) |
| +2 | Мигающий код Chrysler, BCD |
| +3 | Флаги, см. ниже |
| +4, +5 | Маска и смещение байта бита ошибки в битовой карте `$0135` |
| +6, +7 | Код OBD-II в BCD, например `01 22` = P0122; `00 00` — нет |

## Флаги (байт +3)

| Bit | | |
|---|---|---|
| 7 | Ошибка включена. Если бит сброшен, `ThrowNonCriticalError` выходит, ничего не записав | [код] |
| 6 | Влияет на токсичность: учитывается в `$010D` (число кодов OBD-II) и сохраняет стоп-кадр | [код] |
| 5 | Ставит бит 7 в `$0070`, который читает логика лампы (`CheckIfCheckEngineLightShouldBeOn_A_MM`). Стоит только у ошибок зарядки, так что, вероятно, это лампа зарядки | [выведено] |
| 4 | Всегда проходить через счётчик созревания | [код] |
| 3 | Записать сразу, без счётчика | [код] |
| 0-2 | Приоритет стоп-кадра: больший перезаписывает сохранённый | [код] |

## Как сохраняются ошибки

`ThrowNonCriticalError` ($5B0A) получает адрес дескриптора в Y. Ошибка, которая не пишется сразу, занимает один из двух слотов созревания (`$0054`/`$0055`, счётчики `$0056`/`$0057`) и записывается, когда счётчик дойдёт до байта +1. Записанная ошибка ставит свой бит в карте `$0135` и попадает в список восьми последних кодов `$001B`-`$0022` (последний — `$0022`), который DRB читает командой `$10`. Счётчики включений зажигания `$0023`-`$0025` стирают старые коды.

Ошибка, влияющая на токсичность, сохраняет ещё и **стоп-кадр** в `$011E`-`$0126` (`CaptureFreezeFrame`, $EC86): индекс ошибки, нагрузку, температуру ОЖ, кратковременную и адаптивную коррекцию топлива, обороты, скорость и ещё два значения. `LECD7` потом сравнивает текущие обороты и MAP с кадром (проверка OBD-II «схожих условий»). Вместе с подпрограммами ISO 9141 это значит, что FCC 1995 года уже несёт большую часть механики OBD-II.

**Контрольная сумма (код 53).** В обоих образах у дескриптора 2, который сообщает `CaculateChecksum`, сброшен бит включения, так что несовпадение суммы вообще не записывается. В заводских образах B559 (таблица по адресу $D4E9) он включён, поэтому сумму после правок всё равно подгоняйте.

## Различия между образами

- `$D96B` (#145): `91 01 14 13 02 13 12 99` → `91 01 14 d3 02 13 12 99` (5269718 → 5007033)
