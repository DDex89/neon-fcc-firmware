# Карта ввода-вывода

Восстановлена по коду: обращения к регистрам, последовательности запуска АЦП и подпрограммы тестов
исполнительных механизмов (`ATM_*`), каждая из которых управляет одним выходом и тем самым выдаёт его бит.
Достоверность: **[код]** — прямо следует из кода, **[выведено]** — вероятно, нужно подтвердить на плате.
Номера контактов разъёма пока не сопоставлены.

|---|---|---|---|

| PA1 | IC2 | Датчик скорости автомобиля | [код] |
| PA2 | IC1 | Датчик коленвала, передние фронты: главное событие двигателя | [код] |

| PA7 | PAI | Датчик распредвала, оба фронта | [код] |

## АЦП (порт E)

| Канал | Сигнал | |
|---|---|---|
| AN0 | Датчик MAP (читается в синхронном с коленвалом сканировании, `ADCTL = $10`) | [выведено] |
| AN1 | Напряжение бортсети | [код] |
| AN2 | Передний датчик O2 | [код] |
| AN3 | Сигнал детонации, одиночное преобразование в `Isr_TOC4_KnockSample` (`ADCTL = $03`) | [код] |
| AN4 | **Мультиплексированный вход**, выбор битами 0-1 регистра `$0400`: `00` температура охлаждающей жидкости, `01` кнопки круиза, `10` и `11` температура окружающего воздуха и аккумулятора (в коде встречаются оба имени; какое значение выбора чему соответствует, не подтверждено) | [код] |
| AN5 | Читается в коде подцикла рядом с монитором заднего O2; вероятно, задний датчик O2 | [выведено] |
| AN6 | Положение дросселя (TPS) | [код] |
| AN7 | Не читается | [код] |

Используются два режима сканирования: `ADCTL = $10` оцифровывает AN0-AN3, `ADCTL = $14` — AN4-AN7.

| Интерфейс | Назначение | |
|---|---|---|
| SCI (PD0/PD1) | Диагностический канал (протокол DRB II/III, логгинг MP Scan, загрузка кода); скорость переключается на ходу | [код] |

## Внешнее устройство ввода-вывода по адресу $0400

| Регистр | Биты | Назначение | |
|---|---|---|---|
| `$0400` (запись) | 0-1 | Выбор канала аналогового мультиплексора для AN4 | [код] |
| `$0400` / `$0401` (чтение) | | Входы выключателей и состояние (в исходном дизассемблере «SwitchPortAccessReg»); бит 4 в `$0400` — состояние драйвера форсунок, проверяется перед каждой командой впрыска | [код] |
| `$0403` | 0 | Устанавливается при сбросе | [код] |
| | 1 | Выход тахометра (переключается тестом тахометра) | [код] |
| | 2 | Выбор кристалла SPI-драйвера выходов | [код] |
| | 3 | Строб окна детонации: ставится в фазе 3 коленвала, снимается при замере детонации | [код] |
| `$0409` | 3 | Переключается на пути кода ошибки 53 | [код] |
| | 4 | «Пульс», переключается на каждом проходе главного цикла (внешний сторожевой таймер) | [код] |
| `$0410` | | Команда форсункам: `$04` передаёт последние длительности таймерам форсунок | [код] |
| `$0424`, `$0428`, `$042C`, `$0430` | 16 бит | Длительность впрыска, цилиндры 1, 2, 3, 4 (микросекунды) | [код] |
| `$0402`, `$0404`-`$040F` | | Настраиваются в `DealWithConfigurationAndPulseAccumulator_MM` и при сбросе; назначение пока не расшифровано | |

## SPI-драйвер выходов (реле и соленоиды)

Байт ОЗУ `PIA2_Buffer` ($003A) — команда выходам. `SendOutputDriverByte` ($5A29) опускает бит 2 регистра `$0403`, выдвигает
байт по SPI и сохраняет вдвинутый обратно байт (`CCDFlagsX`) — это состояние неисправностей драйвера.
Такое поведение соответствует восьмиканальному последовательному ключу нижнего плеча с диагностикой. [код]

| Бит | Выход (по тестам исполнительных механизмов) | |
|---|---|---|
| 0 | Реле муфты компрессора кондиционера | [код] |
| 1 | Соленоид, которым управляет неназванный тест (вероятно, соленоид EGR) | [выведено] |
| 2 | Реле ASD (тест ASD заодно принудительно выключает выходы катушек) | [выведено] |
| 3 | Реле вентилятора радиатора | [код] |
| 4 | В тестах не встречается | |
| 5 | Соленоид продувки адсорбера | [код] |
| 6-7 | Вакуумный и вентиляционный соленоиды сервопривода круиз-контроля | [код] |

## Прочие выходы

| Выход | Чем управляется | |
|---|---|---|
| Катушки зажигания A / B | OC3 / OC5 | [код] |
| Форсунки 1-4 | Таймеры форсунок внешнего устройства | [код] |
| Тахометр | `$0403` бит 1 | [код] |
| Шаговый мотор РХХ | Тракт SPI, `AisDriveRoutine` | [выведено] |
| Лампа Check Engine, индикатор блокировки ГТ (PTU) | Подпрограммы ламп (`TurnCheckEngineLightOn/Off`, `ATM_PTUIndicator`); выходной регистр пока не прослежен | |
| Обмотка возбуждения генератора | `ControlAlternator`, скважность отсчитывается в `Isr_TOC1_Periodic`; выход пока не прослежен | |
