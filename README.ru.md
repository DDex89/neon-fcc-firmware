# neon-fcc-firmware

Восстановленный, собираемый и прокомментированный исходный код прошивки блока управления двигателем
**Dodge / Plymouth Neon 1995 года** (Chrysler «FCC», Four Cylinder Controller: один 60-контактный
разъём, процессор Motorola 68HC11).

[English version](README.md)

Исходник собирается обратно в оригинальные образы ПЗУ **байт в байт**. На этом держится всё
остальное: код можно читать, переименовывать, комментировать, а потом и менять, точно зная, какая
правка даёт какой байт.

| Вариант | Описание | SHA-256 собранного образа |
|---|---|---|
| `5269718` | Заводская калибровка Chrysler, 2.0 DOHC механика «Racing» (ревизия B от 4874164) | `db0b8819...5669bab7` |
| `5007033` | Калибровка Mopar Performance, 2.0 SOHC механика | `12182bc2...18c3bdc6` |

У обоих образов общий код программы (кодовая база «B4CC»), различаются только калибровки.
Большинство заводских калибровок 1995 года (4874154-4874165, 5013113) построены на более ранней
кодовой базе «B559». Её исходник генерируется из тех же аннотаций в `src_b559/`, и все одиннадцать
заводских образов тоже собираются байт в байт. Оказалось, что B4CC — это B559, в которой больше не
вызываются мониторы OBD-II, расчёт скважности продувки, коррекции по цилиндрам, переменный ограничитель оборотов
и несколько проверок датчиков. Поздние заводские ревизии на базах B4F3 (5269709, 5269712, 5269738) и
B4C2 (5269646) тоже перенесены и собираются так же; см.
[docs/ru/code_bases.md](docs/ru/code_bases.md#сводка-по-функциям).

## Что здесь есть

```
src/                      исходник прошивки (vasm, синтаксис Motorola, 68HC11)
  fcc_<вариант>.asm       головной файл для каждого варианта
  inc/                    регистры 68HC11, переменные ОЗУ, внутренние метки
  code/NN_*.asm           код, разбитый по подсистемам (37 модулей, по порядку адресов)
  cal/<вариант>.asm       калибровки, разложенные по таблицам
src_b559/                 то же для заводской кодовой базы B559 (генерируется, одиннадцать образов)
src_b4f3/, src_b4c2/      то же для баз B4F3 (три образа) и B4C2 (один образ)
annotations/              база знаний, из которой генерируется исходник
  routines.md             описания подпрограмм, пишутся вручную (правьте здесь!)
  comments.txt            комментарии к отдельным командам
  *.json                  метки, имена ОЗУ, описания таблиц, точки входа, разбивка на модули
  bases/<база>/           карта адресов в другую базу, её варианты и описания её собственного кода
tools/
  build.py                сборка и сверка с хешами оригиналов
  gen_source.py           генерация src/ из дампов ПЗУ и аннотаций (--base B559 для src_b559/)
  port_base.py            построение карты адресов из B4CC в другую кодовую базу
  gen_cal_docs.py         генерация справочника калибровок
  gen_fault_docs.py       генерация справочника кодов ошибок
  gen_ram_docs.py         генерация карты ОЗУ
  fccdis.py               отделение кода от данных (дизассемблер рекурсивного обхода)
  import_lloyd.py         разовый импорт аннотаций Роберта Ллойда
docs/en, docs/ru          документация (английская / русская)
```

## Быстрый старт

1. Соберите ассемблер vasm (семейство 6800, синтаксис Motorola), см. [docs/ru/building.md](docs/ru/building.md).
2. `python tools/build.py` собирает оба варианта в `build/` и проверяет SHA-256.
3. `python tools/build.py --base B559` — то же для одиннадцати образов B559 (в `build/B559/`);
   `--base B4F3` и `--base B4C2` — для двух других баз.

Ожидаемый результат:

```
5269718: OK - byte-identical to the original image (sha256 db0b8819...)
5007033: OK - byte-identical to the original image (sha256 12182bc2...)
```

Для сборки дампы ПЗУ не нужны. Они нужны только для перегенерации исходника через
`tools/gen_source.py` (см. [roms/README.md](roms/README.md)).

## Состояние

- 17 образов на четырёх кодовых базах (B4CC 2, B559 11, B4F3 3, B4C2 1) собираются байт в байт, это проверяется в CI.
- Опознано 20 018 команд. Весь код, вызываемый через таблицы указателей, теперь трассируется; осталось
  7 команд в четырёх обрывках, на которые нет ссылок, они помечены как мёртвый код.
- 616 шапок подпрограмм с графом вызовов. Вручную описаны 209 подпрограмм: 198 из них сверены с кодом полностью или частично
  построчно (`[reviewed]`), остальные описаны по исходным названиям (`[from name]`).
- 463 калибровочные таблицы названы и отформатированы: 3D-карты и кривые разложены по строкам.
- Карта ОЗУ с подпрограммами, которые читают и пишут каждый адрес; у каждого адреса, к которому есть
  прямое обращение, есть имя. Где смысл не расшифрован, имя говорит, чья это переменная (`MonEvap_0205`)
  или что она общая (`Var_0183`).

Помощь приветствуется. Улучшить базу знаний значит отредактировать `annotations/routines.md` или
`annotations/comments.txt`, перегенерировать исходник и убедиться, что сборка по-прежнему байт в байт.

## Планы

1. Довести комментарии кода. Сделано: положение двигателя и расписание событий, топливо, зажигание,
   детонация, холостой ход, коды ошибок, протоколы DRB / ISO 9141 / J1979, связь со вспомогательной
   микросхемой и сообщения CCD. Осталось: смысл принимаемых сообщений CCD и переменных, у которых пока только имя владельца.
2. Полностью разобрать железо. Сделано: распиновка разъёма, выводы таймера, каналы АЦП, драйверы
   выходов. Осталось: большая часть битов входов выключателей, вход уровня топлива, регистры
   устройства по адресу $0400 и вспомогательной микросхемы — без их документации дальше не разобрать.
3. Перенести аннотации на другие кодовые базы. Сделано: B559 (перенесена вся разметка, названы её
   собственные добавки, отличия описаны), B4F3 и B4C2. Осталось: B588 — другое поколение 1993 года.
4. «Enhanced Edition»: доработанная прошивка для того же железа (таблицы с большим разрешением, вход
   широкополосного зонда, быстрый логгинг, улучшенная диагностика) на основе проверенного исходника.
   Естественная отправная точка для OBD-II — мониторы, которые уже есть в коде, но не включены в
   расписание.
