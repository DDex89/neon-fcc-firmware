# neon-fcc-firmware

Восстановленный, собираемый и прокомментированный исходный код прошивки блока управления двигателем
**Dodge / Plymouth Neon 1995 года** (Chrysler «FCC», Four Cylinder Controller: один 60-контактный
разъём, процессор Motorola 68HC11).

[English version](README.md)

Исходник собирается обратно в оригинальные образы ПЗУ **байт в байт**. На этом держится всё
остальное: код можно читать, переименовывать, комментировать, а потом и менять, точно зная, какая
правка даёт какой байт.

| Вариант | Описание | SHA-256 собранного образа |
|---|---|---|
| `5269718` | Заводская калибровка Chrysler, 2.0 DOHC механика «Racing» (ревизия B от 4874164) | `db0b8819...5669bab7` |
| `5007033` | Калибровка Mopar Performance, 2.0 SOHC механика | `12182bc2...18c3bdc6` |

У обоих образов общий код программы (кодовая база «B4CC»), различаются только калибровки.
Большинство заводских калибровок 1995 года (4874154, 4874155, 4874159 ...) построены на более ранней
кодовой базе «B559», она пока не разобрана.

## Что здесь есть

```
src/                      исходник прошивки (vasm, синтаксис Motorola, 68HC11)
  fcc_<вариант>.asm       головной файл для каждого варианта
  inc/                    регистры 68HC11, переменные ОЗУ, внутренние метки
  code/NN_*.asm           код, разбитый по подсистемам (37 модулей, по порядку адресов)
  cal/<вариант>.asm       калибровки, разложенные по таблицам
annotations/              база знаний, из которой генерируется исходник
  routines.md             описания подпрограмм, пишутся вручную (правьте здесь!)
  comments.txt            комментарии к отдельным командам
  *.json                  метки, имена ОЗУ, описания таблиц, точки входа, разбивка на модули
tools/
  build.py                сборка и сверка с хешами оригиналов
  gen_source.py           генерация src/ из дампов ПЗУ и аннотаций
  gen_cal_docs.py         генерация справочника калибровок
  fccdis.py               отделение кода от данных (дизассемблер рекурсивного обхода)
  import_lloyd.py         разовый импорт аннотаций Роберта Ллойда
docs/en, docs/ru          документация (английская / русская)
```

## Быстрый старт

1. Соберите ассемблер vasm (семейство 6800, синтаксис Motorola), см. [docs/ru/building.md](docs/ru/building.md).
2. `python tools/build.py` собирает оба варианта в `build/` и проверяет SHA-256.

Ожидаемый результат:

```
5269718: OK - byte-identical to the original image (sha256 db0b8819...)
5007033: OK - byte-identical to the original image (sha256 12182bc2...)
```

Для сборки дампы ПЗУ не нужны. Они нужны только для перегенерации исходника через
`tools/gen_source.py` (см. [roms/README.md](roms/README.md)).

## Состояние

- Обе прошивки собираются байт в байт, это проверяется в CI.
- Опознано 19 757 команд. 181 из них находится в блоках, до которых статический анализ не доходит
  (косвенные переходы или мёртвый код), такие блоки помечены.
- 613 шапок подпрограмм с графом вызовов. Вручную описано 90 подпрограмм: 51 из них сверены с кодом полностью или частично
  построчно (`[reviewed]`), остальные описаны по исходным названиям (`[from name]`).
- 463 калибровочные таблицы названы и отформатированы: 3D-карты и кривые разложены по строкам.
- Многие имена переменных ОЗУ пока условные или безликие (`L0123`).

Помощь приветствуется. Улучшить базу знаний значит отредактировать `annotations/routines.md` или
`annotations/comments.txt`, перегенерировать исходник и убедиться, что сборка по-прежнему байт в байт.

## Планы

1. Довести комментарии кода: расписание топлива и зажигания, синхронизация по коленвалу и
   распредвалу, диагностика.
2. Полностью разобрать железо: 60-контактный разъём, выводы портов, внешнее устройство ввода-вывода по
   адресу $0400.
3. Перенести аннотации на заводскую кодовую базу B559.
4. «Enhanced Edition»: доработанная прошивка для того же железа (таблицы с большим разрешением, вход
   широкополосного зонда, быстрый логгинг, улучшенная диагностика) на основе проверенного исходника.
